# add-standard

Record the external reference-standard certificate details.

Run `node scripts/calibration.mjs add-standard --code=REF-1 --name="Reference standard" --from=2026-01-01 --until=2027-01-01 --certificate="<evidence reference>" --uncertainty="<budget reference>" --actor="<operator>"`. Use `--json` when inspecting the full result. Resolve names from the register first. Replace every angle-bracket value with a verified fact. Never run placeholders.

Report the records, owner, due date and evidence gaps. A finding is not a certification. For a write, read the record first and use the operator’s declared name. Nothing sends or publishes.
