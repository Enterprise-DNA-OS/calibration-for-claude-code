# add-site

Add an operating site.

Run `node scripts/calibration.mjs add-site --code=WLG --name="Wellington" --actor="<operator>"`. Use `--json` when inspecting the full result. Resolve names from the register first. Replace every angle-bracket value with a verified fact; never run placeholders.

Report the records, owner, due date and evidence gaps. A finding is not a certification. For a write, read the record first and use the operator’s declared name. Nothing sends or publishes.
